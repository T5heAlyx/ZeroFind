ZeroFind: Güvenlik Tarama Aracı

ZeroFind, web sitelerinin ve ağ sistemlerinin güvenlik durumunu değerlendirmek için geliştirilmiş kapsamlı bir güvenlik tarama aracıdır. Açık portları tespit eder, yaygın güvenlik açıklarını belirler ve sonuçları detaylı raporlar.

Bir Türk tarafından geliştirildiği için tamamen Türkçe arayüzü sayesinde yerli kullanıcılar için kolay kullanım sağlar ve güvenlik uzmanlarına, sistem yöneticilerine ve web geliştiricilerine değerli bilgiler sunar.

Özellikler

Kapsamlı Port Taraması

ZeroFind, hedef sistemdeki açık portları tespit eder ve bu portlarda çalışan servisleri tanımlar. Bu bilgi, potansiyel saldırı yüzeyini anlamak için çok önemlidir.

Zafiyet Tespiti

Web sunucuları, veritabanları, SSL/TLS yapılandırmaları ve daha fazlasındaki yaygın güvenlik açıklarını tespit eder. Bulunan zafiyetler, önem derecesine göre sınıflandırılır.

Çift Arayüz

ZeroFind hem komut satırı arayüzü hem de web arayüzü sunar. Terminal severlere komut satırı esnekliği, görsel arayüz tercih edenlere ise modern web tabanlı deneyim sunar.

Görsel Raporlama

Tarama sonuçları, anlaşılması kolay grafikler ve tablolarla görselleştirilir. Bu görsel öğeler, güvenlik durumunuzun anlık görüntüsünü verir.

Çoklu Tarama Seviyeleri

Hızlı taramadan derinlemesine analize kadar farklı tarama seviyeleri sunar. İhtiyacınıza göre hız ve detay dengesi kurabilirsiniz.

Kullanım Kılavuzu

Web Arayüzü

Web arayüzünü kullanmak için:

  1. Ana sayfadaki tarama formunu kullanarak bir hedef (domain veya IP adresi) belirleyin
  2. Tarama tipini seçin (hızlı, standart veya derinlemesine)
  3. "Taramayı Başlat" düğmesine tıklayın
  4. Sonuçlar tamamlandığında otomatik olarak gösterilecektir

Terminal Arayüzü

Terminal arayüzünü kullanmak için:

python zerofind.py -t

Komut satırı parametreleri:

  • -t veya --terminal: Terminal arayüzünü çalıştırır
  • -w veya --web: Web arayüzünü çalıştırır

Önemli Uyarı

ZeroFind'ı yalnızca kendi sistemlerinizde veya tarama yapmak için açık izin aldığınız sistemlerde kullanın. İzinsiz güvenlik taramaları yasal sonuçlar doğurabilir.

Teknik Detaylar

ZeroFind, aşağıdaki teknolojileri kullanarak geliştirilmiştir:

  • Backend: Python, Flask, Python-nmap, Socket
  • Frontend: HTML, CSS, JavaScript, Bootstrap, Chart.js
  • Tarama Motorları: Nmap, özel Python modülleri

ZeroFind Wr4th tarafından geliştirilmiş, açık kaynak bir projedir ve sürekli olarak geliştirilmektedir. Öneri ve katkılarınızı bekliyoruz.
